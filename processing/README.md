# Processing Service

The Processing service subscribes to DDS CPM topics, decodes each received CPM, and republishes the contained object data in an enriched, application-friendly JSON format on MQTT, DDS, and Zenoh.

### What It Does

For each incoming CPM the Processing service:
1. Extracts sender station metadata (position, speed, heading, altitude, acceleration) from the station's last known CAM, looked up via the Locator
2. Converts ETSI-encoded relative x/y distances back to absolute WGS-84 lat/lon coordinates
3. Decomposes object speed and heading into north/east (x/y) velocity components
4. Maps ETSI integer codes for sensor types and object classifications to human-readable strings
5. Publishes the enriched object list on all configured outputs

### Output Topic: `objects`

The output is published on the `objects` topic across all enabled transports. See the root [README.md](../README.md#processed-objects----output-topic-objects) for the full JSON format and field reference.

### Locator

The Processing service includes its own Locator component that tracks the kinematic state of CPM-sending stations by listening to their CAM broadcasts. This data is used to populate the `sender` block of the output message. In `static` mode (when the processing station is receiving its own CPMs), the configured `station_id` is used with a minimal static entry.

## `config.ini` Configuration

```ini
[general]
log_level = info
prometheus = true
prometheus_port = 9103

[processing]
domain_id = 0
station_type = 15
station_id = 0
repeat_id_interval = 3600
performance_logs = false

dds_output_topic = objects

local_mqtt_enable_publisher = true
local_mqtt_host = 127.0.0.1
local_mqtt_port = 1883
local_mqtt_output_topic = objects

remote_mqtt_enable_publisher = false
remote_mqtt_host = atcll-services.nap.av.it.pt
remote_mqtt_port = 1884
remote_mqtt_username =
remote_mqtt_password =
remote_mqtt_output_topic = p1/objects

zenoh_endpoint = 127.0.0.1
zenoh_output_topic = objects

[locator]
station_id = 1
location_provider = static ; static, mqtt or dds
mqtt_host =
mqtt_port =
mqtt_topic =
domain_id = 0
dds_topic =
```

| Key | Default | Description | Range |
|---|---|---|---|
| `general.log_level` | `info` | Logging verbosity | `trace`, `debug`, `info`, `warn`, `error`, `critical`, `off` |
| `general.prometheus` | `false` | Enable Prometheus metrics endpoint | `true/false` |
| `general.prometheus_port` | `9103` | Port for the Prometheus metrics HTTP endpoint | `1024`–`65535` |
| `processing.domain_id` | `0` | DDS domain ID — **change this** to match the Vanetza or Generation domain | `0` to `230` |
| `processing.station_type` | `15` | Own station type — only needed when processing CPMs generated by this same station | `5` for OBU, `15` for RSU |
| `processing.station_id` | `0` | Own station ID — only needed when processing CPMs generated by this same station | - |
| `processing.repeat_id_interval` | `3600` | Time window (seconds) used to generate stable `uniqueID` values for processed objects — object IDs are stable within each window and reset at the boundary | `>0` |
| `processing.performance_logs` | `false` | Write CSV performance logs to `/logs/processor.csv` | `true/false` |
| `processing.dds_output_topic` | `objects` | DDS topic to publish processed objects | - |
| `processing.local_mqtt_enable_publisher` | `true` | Enable local MQTT output | `true/false` |
| `processing.local_mqtt_host` | `127.0.0.1` | Local MQTT broker address | - |
| `processing.local_mqtt_port` | `1883` | Local MQTT broker port | - |
| `processing.local_mqtt_output_topic` | `objects` | Local MQTT topic to publish processed objects | - |
| `processing.remote_mqtt_enable_publisher` | `false` | Enable remote MQTT output (e.g. cloud broker) | `true/false` |
| `processing.remote_mqtt_host` | `127.0.0.1` | Remote MQTT broker address | - |
| `processing.remote_mqtt_port` | `1883` | Remote MQTT broker port | - |
| `processing.remote_mqtt_username` | `""` | Remote MQTT username | - |
| `processing.remote_mqtt_password` | `""` | Remote MQTT password | - |
| `processing.remote_mqtt_output_topic` | `objects` | Remote MQTT topic to publish processed objects | - |
| `processing.zenoh_endpoint` | `127.0.0.1` | Zenoh locator for peer/router discovery | - |
| `processing.zenoh_output_topic` | `objects` | Zenoh topic to publish processed objects | - |
| `locator.station_id` | `1` | Station ID to look up in own-CPM mode | `>0` |
| `locator.location_provider` | `static` | Position source for sender lookup: `static`, `mqtt`, or `dds` | - |
| `locator.mqtt_host` | `127.0.0.1` | MQTT broker for CAM subscription | - |
| `locator.mqtt_port` | `1883` | MQTT broker port | - |
| `locator.mqtt_topic` | `""` | CAM/VAM topic — supported: `vanetza/in/cam`, `vanetza/own/cam`, `vanetza/out/cam`, `vanetza/in/cam_full`, `vanetza/in/vam`, `vanetza/out/cam_full` | - |
| `locator.domain_id` | `0` | DDS domain ID for CAM subscription — **change this** to match the station data domain | `0` to `230` |
| `locator.dds_topic` | `""` | CAM/VAM DDS topic — same supported values as `mqtt_topic` | - |
